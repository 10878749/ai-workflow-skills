在 Codex 中试用

Python 3.10+
  1. 下载并解压技能合集

    在解压目录打开终端，先预览要安装的内容。

  2. 选一项技能安装
    python scripts/install.py --skill reuse-first

    确认目标目录后，加上 --apply 才会写入。已有不同内容不会被覆盖。

    python scripts/install.py --skill reuse-first --apply
  3. 在新聊天里给出任务

    例如：“请用 $reuse-first，先为这个需求寻找并评估成熟开源基础。”

安装全部、选择目录与兼容说明

安装全部：python scripts/install.py --all --apply。自选目录：增加 --dest 目标技能目录。

安装器优先采用 CODEX_HOME；存在旧版个人目录时沿用，否则使用标准用户技能目录。其他宿主可按其要求复制单项文件夹，暂未承诺跨宿主运行兼容性。插件兼容清单已随包提供，未声称通过应用商店审核。

无 Python 时，可让你的 coding agent 阅读解压目录的 README，按当前宿主规则安装所选技能，并保留已有文件。
