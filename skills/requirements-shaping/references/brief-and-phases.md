# 简记与分期模板

复用项目已有结构；下面的字段可合并或删除，不要求用户填表。

```text
目标：谁在什么场景下，完成什么，解决什么问题
当前阶段目的：展示定位／验证交互／消除技术不确定性／实际使用
成功条件：可观察结果；用户要求与假设分列
事实与约束：现有能力、平台、数据、时间、已知资源
概念与职责：关键名词、操作者、对象与边界
关键路径：入口 → 核心动作 → 结果 → 返回／恢复
必须保留：已存在且本轮需要保护的行为
本轮范围与暂缓项：说明原因或前提

阶段：
- 交付什么可见产物
- 消除什么不确定性或满足哪条用途
- 必要依赖和真实／模拟边界
- 完成判据与检查入口

变化影响：旧定义、受影响内容和更新入口
未决问题：仅保留会影响方向或实施的问题
下一动作：已授权可执行部分与确实待决定部分
```

要求到验收的映射应保持轻量：一个重要要求对应一个行为或结果即可。没有能力验证的要求标为待验，不凭“已设计”写成“已完成”。
