# 按需使用的材料结构

已有表格或模板优先，以下是核对维度，不要求新增多份文档。

```text
受审对象：包名、摘要、版本、实际范围、核实时间
统计口径：物理／有效行，空行注释，生成／测试／第三方，重复和单位

模块：名称、职责、包内路径、文件角色、来源状态与证据
统计：文件数、字节／KiB、已知行数、未知项、共享范围
功能：需求、实现路径、运行证据、限制
变更：前后版本、具体行为、代码和运行截图、相对路径与行号

结论：当前证据支持的内容
待补：缺少的文件、范围、授权、来源或专业验收证据
交付：实际文档／图片／归档包及摘要
```

相对路径、行号和截图属于受审版本；目录里的“最新”文件不自动属于这次送出的包。核对实际附件而不是仅核对工作目录。
