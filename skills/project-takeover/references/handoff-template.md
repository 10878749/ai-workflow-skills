# 精简交接模板

仅在需要新增入口时使用；已有交接文档优先原位更新。删除无关项，普通任务可压缩成几个段落。不要让用户填表。

```markdown
# 当前开发交接

更新时间：写明日期、时间和时区
本轮目标／范围：
当前结论：可继续／部分可继续／具体阻碍

## 工作对象

| 职责 | 权威路径或地址 | 身份与状态 | 证据及核实时间 |
|---|---|---|---|
| 主项目源码 | 实际目录 | 分支、完整 SHA、已有改动 | Git 本次查询 |
| 配套仓库 | 按需填写 | 各自独立记录 | 证据入口 |
| 当前运行实例 | 实际入口 | 环境、配置、版本或待核实 | 本次观察／历史日期 |
| 数据与配置 | 存放入口 | 已核实内容及未知项 | 不包含秘密值 |

构建物与源码的对应证据：按需记录；缺失时明确未证实。
必须保留的原有改动／行为：

## 恢复与运行

必要环境、工作目录、目标配置：
现有启动／检查入口：
当前进程或服务、访问地址、停止方式：按需填写
已知会写入或访问外部系统的步骤：

## 当前进展与验证

| 项目 | 状态及证据 | 限制／下一步 |
|---|---|---|
| 具体行为或任务 | 本次实测／历史记录／推断／待核实；日期、入口与结果 | 失败、跳过和未验收范围 |

## 下一动作

从哪个未完成步骤继续：
在哪个目录执行什么命令或操作：
预期结果和完成判据：
必要前提／阻碍：
当前授权允许做到哪里：仅当确有范围限制时记录

相关契约、决策与历史记录入口：
版本说明：若记录尚未提交，写基线 SHA＋未提交差异。
```

交接前检查：命令和路径存在；记录的验证属于明确版本；推断没有写成实测；下一动作可执行或阻碍具体；只保留一个当前入口；没有秘密、过期默认账号或未经核实的部署承诺。
