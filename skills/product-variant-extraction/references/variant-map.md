# 变体地图与检查方法

## 最小变化地图

按当前目标填写，复用项目已有文档，不强制新建文件。

| 能力 | 源领域含义 | 目标领域变化 | 处理方式与入口 | 验证 |
|---|---|---|---|---|
| 实体与筛选 | 书籍、作者、阅读需求等 | 按目标产品确定 | 复用／配置／替换 | 一个实际目标样例 |
| 获取与质量 | 来源、适用性和评价方式 | 新来源与判据 | 领域适配点 | 来源支持内容，缺失时处理 |
| 交互与状态 | 抽取、详情、收藏等 | 行为是否仍适用 | 共用状态与目标文案 | 正常与相关失败路径 |
| 服务与存储 | 旧项目配置与数据 | 独立归属 | 新身份、绑定和缓存范围 | 本地／线上分别说明 |

运行示例与参数应基于具体产品，不把这张例表当现成需求。

## 标识残留扫描

脚本需要 Python 3.10+，仅使用标准库。显式提供扫描目录和标记 JSON，标记文件宜放在工作目录而非目标产品中，以免扫描自身。示例：

```json
{"markers": [
  {"id": "old-brand", "needle": "Example Reading", "where": "both", "case_sensitive": true},
  {"id": "old-endpoint", "needle": "old.example.invalid", "where": "content", "case_sensitive": false}
]}
```

```text
python -X utf8 SKILL_DIR/scripts/scan_markers.py VARIANT_ROOT --markers MARKERS_JSON
```

`where` 是 `path`、`content` 或 `both`，使用字面匹配，不解释正则；输出标记 ID、包内路径和内容行号，不输出正文或标记值。结果不应自动发送给其他人。

默认排除 `.git`、依赖与缓存，跳过链接；最多检查 10000 个文件和 10000 个目录，可显式调整预算。内容仅扫描不大于 2 MiB 的 UTF-8／带 BOM 文本。二进制、超限、不可解码、不可读及预算限制都会报告；有未覆盖内容时退出码 2。匹配本身不决定退出码，不等于缺陷；无匹配也不证明无秘密或已安全隔离。

命中历史说明可能合理，命中运行配置、部署身份或业务字段通常需要追踪。逐处判断后只做符合目标语义的修改，避免全局替换损坏 API 字段、外部标识和历史事实。

## 实例应留下什么

- 对应源版本与目标场景。
- 已证明复用的能力、必须替换的领域含义和剩余缺项。
- 新旧配置、数据和部署身份的归属及核查证据。
- 一个可运行目标样例与实际检查结果。
- 下一次衍生时最先需要修改的入口。
