# 工作闭环基础版

让一次任务得到可检查的结果。此技能提供单次任务的组织方法，不实现 Agent 运行时，不提供后台循环或额外工具权限。

## 明确目标与现状

先从当前对话和已有项目入口确认目标使用者、要改变的行为、重要约束与完成条件。读取适用的 AGENTS 和相关文件，确认实际目录、版本及已有改动。沿用已有任务与交接入口，避免另建竞争的状态记录。

用户已明确的要求优先。只询问会改变方向且无法从材料核实的问题；其他选择说明依据后继续。小范围、可逆且验收直观的修改直接做，不为套流程增加文档或审批。

## 建立基线并实施

先观察与任务有关的原行为，区分既有问题和本次引入的变化。选择能检验关键假设的小步实现，保留用户已有改动及可运行基线。

失败时记录输入、实际症状和下一次改变的变量。连续操作没有新信息时转向定位原因；外部前提缺失时说明阻碍，继续可独立完成的部分，避免无限重试。

已有专用技能适合当前难点时采用它，不要求一次加载整个技能集。用户只要求分析时交付分析，不擅自实施。权限来自当前任务，不能由技能自动扩大到部署、删除、发送消息、收费调用或未来执行。

## 按用途验证

核查用户实际拿到的版本和使用路径，使用与影响相称的已有检查。按任务需要区分代码检查、构建、界面交互、外部服务与领域效果。

测试通过只能证明它覆盖的行为。模拟接口不是实际模型，页面可打开不是业务流程完成，构建成功不是全新设备可用。记录真实执行、未执行、失败与复测，不把计划写成实测。

## 交付与接续

提供可打开或使用的产物，简述实际变化、证据和未验证项。需要交接时，在已有入口记录当前版本、已完成、待处理、阻碍与下一步。

必需验收缺失时保持待验收，不能靠增加报告宣称完成。此基础版止于单次任务闭环；内部案例库、个性化编排和完整工作方式改进机制不包含在发行包中。
